# 🦓 Zebra Coffee – Web Technologies Assignment 2

This repository contains the second practical assignment for the Web Technologies course. In this phase, we brought to life and styled the HTML pages created in the first assignment using exclusively pure CSS (without the use of any external libraries or frameworks like Bootstrap or Tailwind).

## 👥 Team

* **Yelzhan Baurzhanov** — layout and styling of personal pages (FAQ, Feedback, etc.), CSS Grid setup, absolute positioning, and form styling.
* **Nurzhan** — layout and styling of personal pages (Menu, About, etc.), working with tables, positioning, and Flexbox layouts.

## 🚀 Project Description

We developed a design system for the Zebra Coffee shop website, focusing on a warm color palette (Cream/Beige, Dark Brown, Black) and typography that conveys the cozy atmosphere of the cafe (Playfair Display and classic sans-serif fonts).

The project implements all the core requirements of Assignment 2:

* A semantic layout that is fully responsive within basic media queries.
* Application of modern CSS layouts: **CSS Flexbox** (for navigation and cards) and **CSS Grid** (for FAQ grids and other lists).
* Practical demonstration of all 4 positioning types: `static`, `relative`, `absolute`, and `fixed`.
* In-depth utilization of selectors (child, adjacent sibling, attribute selectors, pseudo-classes, and pseudo-elements).
* Successful management of the CSS cascade and specificity.

## 🛠 Technologies and Approaches

* **HTML5:** Semantic tags (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<figure>`, `<footer>`).
* **CSS3:** Separation of styles into shared and individual stylesheets.
* **Box Model:** Precise control over margins, padding, borders, and `box-sizing`.
* **W3C Validation:** Both HTML and CSS code pass the W3C validator with zero errors.

## 🖥 How to Run the Project

The project runs locally and does not require a web server to function.

1. Clone the repository: `git clone <repository-link>`
2. Open the `index.html` file in any modern web browser.
