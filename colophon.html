How This Site Was Made

Tools and Process

I wrote all the code by hand in Visual Studio Code, without using any page builders or templates, since the assignment required writing plain HTML myself. The project is organized into four pages — index.html, menu.html, booking.html, and colophon.html — all linked through the same navigation menu, with a shared images/ folder for photos.

Most of the content came from visiting Zebra Coffee in person. I took photos of the interior and the menu board on site, and wrote down the address, opening hours, and phone number in a paper notebook before typing them into the aside section. The customer quote on the booking page is a real review I collected, not something I made up. For the location link, I used 2GIS to find the exact map entry for the cafe.

I tried to pick tags based on meaning rather than appearance — for example, using <aside> for contact details because they're supporting information, not part of the main story, and <q> for the inline customer quote instead of just styling it in bold. Every tag choice was made with a reason, not by default habit.
